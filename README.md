## Текущая задача
- ПК отправляет ARP запросы → но ответ от STM32 на проводе не появляется.
- При этом в UART у STM32:
HAL_ETH_Transmit_IT -> HAL_OK
HAL_ETH_TxCpltCallback
То есть:
- MAC принял пакет
- DMA считает передачу успешной
- Но кадр не выходит на PHY / провод.

STM32 считает, что отправил пакет, но PHY его не получает.

Скорее всего: RX пины правильные → есть ARP в Wireshark, а TX пины физически не подключены к PHY
