# 2CAN-Eth - ветка для временной копии проекта
## Ветки
- **main** - стабильная версия
- **Fixing** - ветка для исправлений и тестирования всего проекта
- **Test_Simple_TCP** - ветка для тестирования части только с TCP-сервером
- **Fixing_Only_TCP** - ветка для резервной копии только теста TCP

## Последняя версия (08.08)
Медленная работа TCP, возможная причина - конфликт одновременного доступа RX/DMA и TX/DMA к разделяемой памяти на высокой частоте шины.
