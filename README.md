# 2CAN-Eth - ветка для временной копии проекта
## Ветки
- **main** - стабильная версия
- **Fixing** - ветка для исправлений и тестирования всего проекта
- **Test_Simple_TCP** - ветка для тестирования части только с TCP-сервером

## Последняя версия (10.09)
1. Ethernet. Результат: 93–95 Мбит/с на плате, стабильно:
	- увеличен TX-пул (4→6 слотов).
	- поднят приоритет задачи EthIf, отвечающей за приём данных.
2. Скорость CAN. Результат: система стабильно держит ~1500–2278 кадров/с (~0.2–0.3 Мбит/с).
3. Скорость работы NetCan. На самоприёме (self-reception) ~100 кадров/с, беспрерывная передача в течение 40с 
4. Тестировала с помощью:
	- slcan_stress_test.py (нагрузочный тест всей системы)
	- check_ethernet_only.py (проверка работы NetCAN только по Ethernet)
	- netcan_ramp_test.py (мелкий ступенчатый поиск потолка)
	- test_netcan.py (интерактивный/авто-последовательный тест с расшифровкой ответов, режимы normal/self/listen)

## Дальнейшие изменения
