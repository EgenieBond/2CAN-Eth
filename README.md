# 2CAN-Eth
Автор: Бондаренко Е.А.

## Ветки
- **main** - стабильная версия
- **Fixing** - ветка для исправлений и тестирования всего проекта
- **Test_Simple_TCP** - ветка для тестирования части только с TCP-сервером

## Последняя версия (30.09)
- в проект был включен FDCAN2 для работы с 2мя каналами
- получена масимальная текущая скорость работы всех частей программы
- добавление нескольких клиентов в проект
- проверена корректная передача между двумя NETCAN, между STM32 и NETCAN, между двумя STM32
- проверена поддержка всех стандартных скоростей

## Доп. файлы проекта
- check_2_netcans_simple.ру - скрипт, которым все тестировалось
- замер_скорости.xlsx - таблица замеров скоростей передачи между STM32 и NETCAN
